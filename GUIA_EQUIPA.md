## 📥 PASSO 1: CLONAR DO GITHUB

**Primeira vez apenas:**

```bash
git clone https://github.com/RuiSimoesDTE/gestao-de-stocks-dt.git
cd gestao-de-stocks-dt
```

Isto cria uma cópia local do programa na vossa máquina.

---

## ▶️ PASSO 2: ABRIR O PROGRAMA

```
Entrar em: gestao-de-stocks-dt/app/
Duplo clique em: gestao_armazem_catenaria.html
```

**Tela de login aparece** → Entrem com vosso email/password

---

## 💾 PASSO 3: TRABALHAR E SINCRONIZAR

### Depois de fazer alterações:

```bash
# 1. Ver o que mudou
git status

# 2. Adicionar ficheiros
git add .

# 3. Fazer commit (descrever o que fez)
git commit -m "Descrição breve do que fez"

# 4. Enviar para GitHub
git push origin master
```

### Para receber atualizações de outros:

```bash
# Antes de começar a trabalhar
git pull origin master
```

---

## 📋 FLUXO DIÁRIO

```
1. MANHÃ:
   git pull origin master      (receber atualizações)

2. TRABALHO:
   Abrir programa e trabalhar  (tudo sincroniza)

3. FIM DO DIA:
   git status                  (ver alterações)
   git add .
   git commit -m "Seu resumo"
   git push origin master      (enviar para GitHub)
```
