ESTRUTURA DOS FICHEIROS JSON GERADOS
═════════════════════════════════════════════════════════════════

Cada poste contém os seguintes campos:

  numero: Identificação do poste (ex: 05-10)
  estado: Estado do poste (existente, novo, desmontar)
  montagem: Tipo de montagem (A, B, C ou vazio)
  montagem_ref: Referência de montagem (EC-232, E-6177, etc)
  tirFix: Código de fixação do tirante
  consFix: Código de fixação da consola
  outrosEquip: Array com equipamentos adicionais
    - cod: código da peça (EC-xxx, E-xxxx, C-xxxxx, SAP 7 dígitos)
    - desc: descrição ou referência
  desmontar: Array com peças a desmontar (DESM01, etc)
  cotas: Object com cotas extraídas (H, D, S, E, F, A, C, B)
  notas: Observações (presença de tirante, consola, antibalançante)
  pdf: Ficheiro PDF origem
