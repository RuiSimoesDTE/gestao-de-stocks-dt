COMO USAR O MANUAL:

1. NAVEGAÇÃO:
   - Use o Índice no topo para ir direto a uma secção
   - Clique no título de uma secção para ir para lá
   - Use Ctrl+F para pesquisar por palavra-chave

2. LEITURA:
   - Cada secção tem: [IMAGEM ANOTADA] + [EXPLICAÇÃO]
   - Leia o "COMO USAR" para passo a passo
   - Consulte as "DICAS RÁPIDAS" para atalhos

3. IMPRESSÃO:
   - Ctrl+P para imprimir
   - Selecione "Guardar como PDF" se desejar
   - Layout optimizado para papel A4

4. PESQUISA:
   - Ctrl+F abre o search do navegador
   - Procure por funcionalidade ou palavra-chave
   - Ex: "pesquisar stock", "entrada manual", "backup"
