A página inicial mostra o menu lateral com todas as funcionalidades da aplicação. Está organizada em 4 áreas principais: Obras, Projeto, Armazém e Gestão.

2️⃣ Stock - Consultar Materiais

📸 SCREENSHOT ANOTADA
(Painel de Stock com Tabela)

Será incluída a imagem com:
1️⃣ Campo "Pesquisar código"
2️⃣ Dropdown "Armazém"
3️⃣ Botão "Exportar CSV"
4️⃣ Tabela de materiais

O QUÊ

O painel de Stock mostra todos os materiais disponíveis no armazém, com filtros por código, armazém, fornecedor e tipo. Calcula o valor total do stock com preços SAP.

PARA QUÊ

Permite consultar rapidamente a quantidade disponível de qualquer material e saber se está em falta. Mostra os materiais com stock baixo ou esgotado em destaque.

COMO USAR

  1. Pesquisar: Escreve o código, descrição ou parcialmente no campo "Pesquisar código / descrição"
  2. Filtrar por armazém: Seleciona no dropdown "Todos os armazém" se queres ver um armazém específico
  3. Filtrar por fornecedor: Seleciona no dropdown "Todos os fornecedores"
  4. Filtrar por tipo: Seleciona no dropdown "Todos os tipos"
  5. Ver opções: Seleciona "Todos", "Só com stock", "Só stock baixo/esgotado"
  6. Exportar: Clica "⬇ Exportar CSV" para fazer download em Excel
  7. Ver detalhes: Clica no nome de um material para ver o histórico completo

DICAS RÁPIDAS

✅ Materiais com "(empty)" = stock vazio
✅ Materiais com "(sem código)" = precisam código SAP
✅ Valor total = só conta materiais com preço SAP
✅ Filtros funcionam em tempo real

3️⃣ Entradas - Registar Materiais que Chegam

📸 SCREENSHOT ANOTADA
(Formulário de Entradas)

Será incluída a imagem com:
1️⃣ Campo "Nº Pedido de Compra"
2️⃣ Campo "Data de entrega"
3️⃣ Botão "Registar entrada"
4️⃣ Opção "Entrada manual"

O QUÊ

Regista quando materiais chegam ao armazém. Pode ser por pedido de compra, manualmente ou importando do SAP (CSV).

PARA QUÊ

Actualiza o stock quando novos materiais chegam. Rastreia quem forneceu, quando chegou e qual era o pedido de compra associado.

COMO USAR - ENTRADA POR PEDIDO DE COMPRA

  1. Escreve o nº do Pedido de Compra (ex: 4500851896)
  2. Seleciona a data de entrega (DD/MM/YYYY)
  3. Confirma o armazém de receção (ex: "Armazém Catenária")
  4. Escreve o documento/guia se tiver (nº da guia SAP)
  5. Clica "Registar entrada" (botão verde)

COMO USAR - ENTRADA MANUAL

  1. Seleciona "Entrada manual"
  2. Escreve o código do material (SAP ou interno)
  3. Escreve a quantidade que chegou
  4. Seleciona o armazém
  5. Seleciona a data
  6. Preenche opcionalmente: Nº Pedido, Documento/Guia, Fornecedor, Observações
  7. Clica "Registar entrada"

DICAS RÁPIDAS

✅ Se o pedido existe, mostra os materiais automaticamente
✅ Sem pedido? Preenche os dados manualmente
✅ Dados gravados aparecem no histórico com data/hora exacta
✅ Pode fazer múltiplas entradas do mesmo pedido (parciais)

4️⃣ Saídas - Registar Materiais que Saem

📸 SCREENSHOT ANOTADA
(Formulário de Saídas)

Será incluída a imagem com:
1️⃣ Dropdown "Tipo de saída"
2️⃣ Campo "Material"
3️⃣ Campo "Quantidade"
4️⃣ Botão "Registar saída"

O QUÊ

Regista quando materiais saem do armazém para a obra, para outro armazém (transferência) ou para outras actividades.

PARA QUÊ

Reduz o stock quando materiais são usados ou movidos. Permite filtrar por datas e localizar saídas específicas no histórico.

COMO USAR

  1. Tipo de saída: Seleciona "Material individual" ou "Material de montagem"
  2. Material: Escreve o código (aparece search automática)
  3. Quantidade: Quanto está a sair (verifica stock disponível)
  4. Armazém de origem: Onde está guardado
  5. Data: Quando sai (DD/MM/YYYY)
  6. Destino/Obra/Frente: Onde vai (ex: obra Vendas Novas, equipa de campo, etc.)
  7. Opcional: Pedido, Requisição/Documento, Observações
  8. Clica "Registar saída"

FILTRAR SAÍDAS ANTERIORES

  1. Seleciona datas "De" e "Até"
  2. Escreve filtro (código, descrição, destino)
  3. Clica "Filtrar"

DICAS RÁPIDAS

⚠️ Stock insuficiente? A app mostra erro (não permite saída negativa)
✅ Saídas para "montagem" descontam automaticamente dos componentes
✅ Histórico mostra todas as saídas anteriores
✅ Pode filtrar por múltiplos critérios

5️⃣ Transferências entre Armazéns

📸 SCREENSHOT ANOTADA
(Formulário de Transferências)

1️⃣ Campo "Material"
2️⃣ Dropdown "De (armazém)"

O QUÊ

Move materiais entre armazéns diferentes (ex: Armazém Catenária → Estaleiro, ou Vendas Novas → Pampilhosa).

  6. Opcional: Documento/Guia, Observações

DICAS RÁPIDAS

✅ Quantidade sai de um armazém e entra no outro no mesmo dia
✅ Pode filtrar transferências por datas
✅ Se mover para outra obra (Pampilhosa), regista também em "Guias AT"

6️⃣ Encomendas - Pedidos de Compra (SAP)

📸 SCREENSHOT ANOTADA
(Tabela de Encomendas)

Será incluída a imagem com:
1️⃣ Campo de Pesquisa de PC
2️⃣ Filtro de Status
3️⃣ Coluna "Qtd Pedida"
4️⃣ Coluna "A ser Fornecida"

O QUÊ

Base de dados de todos os pedidos de compra (PC) do SAP. Mostra o material, quantidade pedida, quanto já foi entregue e quanto falta.

PARA QUÊ

Permite saber qual é o status de cada encomenda e quando deve chegar material. Facilita registar entradas verificando o que foi encomendado.

COMO USAR

  1. Pesquisar: Escreve número do pedido (ex: 4500851896)
  2. Filtros: Por status (Aberto, Parcialmente Recebido, Completo)
  3. Ver detalhes: Clica numa linha para ver todos os materiais dessa PC
  4. Criar entrada: Quando chega material, vai a "Entradas" e refere este nº de PC

SIGNIFICADO DOS VALORES

  • Qtd Pedida: Total que foi encomendado
  • Qtd Recebida: Quanto já chegou
  • A ser Fornecida: Quanto ainda falta chegar
  • Status: Aberto = ainda falta; Completo = já chegou tudo

DICAS RÁPIDAS

✅ Encomendas importadas do SAP periodicamente via CSV
✅ Se "A ser fornecida" = 0, material chegou completamente
✅ Clica na PC para ver histórico de recepções parciais
✅ Útil para rastrear atrasos de fornecimentos

✅ Ideal para gerar mapas mensais de consumo
✅ Pode filtrar por período (ex: 01/08 a 31/08)

1️⃣1️⃣ Backup e Restauração

📸 SCREENSHOT ANOTADA
(Botões de Backup)

Será incluída a imagem com:
1️⃣ Botão "Backup (JSON)"
2️⃣ Botão "Restaurar"
3️⃣ Mensagem de confirmação
4️⃣ Ficheiro transferido

O QUÊ

Faz download de todos os dados (materiais, movimentos, encomendas, etc.) num ficheiro JSON. Permite restaurar dados anteriores se necessário.

PARA QUÊ

Salvaguardar todos os dados antes de grandes alterações ou mudanças de computador. Protege contra perda de informação e permite recuperação rápida.

COMO FAZER BACKUP

  1. Clica no botão "Backup (JSON)" no topo da página
  2. O ficheiro é automaticamente transferido para a pasta Downloads
  3. Nome do ficheiro: dte_backup_YYYYMMDD_HHMMSS.json
  4. Guarda o ficheiro num local seguro (ex: OneDrive, pen, etc.)

COMO RESTAURAR

  1. Clica no botão "Restaurar" no topo
  2. Seleciona um ficheiro JSON de backup anteriormente guardado
  3. ⚠️ ATENÇÃO: Confirma (substitui TODOS os dados actuais)
  4. A página recarrega com os dados do backup
  5. Verifica que tudo está correcto

BOAS PRÁTICAS

⚠️ Faz backup regularmente (pelo menos 1x por semana)
⚠️ Antes de mudanças grandes (importações SAP, etc.)
⚠️ Guarda backups com datas no nome para rastreabilidade
⚠️ O backup inclui TUDO: materiais, movimentos, encomendas, desenhos, etc.

DICAS RÁPIDAS

✅ Ficheiro JSON é texto (pode abrir com Bloco de Notas)
✅ Cada backup é independent (podes ter múltiplos)
✅ Restauração é instantânea (recarrega a página)
✅ Antes de restaurar, faz backup do estado actual!

O QUÊ

Permite configurar armazéns, tipos de material, fornecedores, e outros parâmetros da aplicação. Customiza a app para diferentes estruturas de armazém.

PARA QUÊ

Gerir os dados mestres da aplicação. Adicionar novos fornecedores, definir tipos de material, e controlar que locais de armazenagem estão disponíveis.

COMO USAR - ARMAZÉNS

  1. Vai a "Definições" > "Armazéns"
  2. Para adicionar: Escreve o nome e clica "Adicionar"
  3. Para remover: Clica "Remover" (apenas se sem stock/movimentos)

  1. Vai a "Definições" > "Tipos"
  2. Para adicionar: Escreve o tipo (ex: "Cabos", "Estrutura") e clica "Adicionar"
  3. Tipos aparecem nos filtros e dropdowns automaticamente

COMO USAR - FORNECEDORES

  1. Vai a "Definições" > "Fornecedores"
  2. Para adicionar: Escreve o nome/código e clica "Adicionar"
  3. Aparece na lista de fornecedores em entradas/encomendas

CUIDADOS IMPORTANTES

⚠️ NÃO apagar armazéns que têm stock ou movimentos históricos
⚠️ Tipos e fornecedores usados aparecem nos filtros automaticamente
⚠️ Mudanças de parâmetros afectam dados futuros (não retroactivos)
⚠️ Faz backup antes de alterações grandes

DICAS RÁPIDAS

✅ Armazéns devem ser únicos (evita duplicados)
✅ Tipos e fornecedores podem ter nomes/códigos iguais aos do SAP
✅ Configuração é local (não sincroniza com SAP)
✅ Manter nomes consistentes para facilitar pesquisa

⚡ Guia Rápida - Atalhos e Dicas Finais

🎯 TAREFAS MAIS COMUNS

TAREFA PASSOS
Consultar stock de um material Stock → Pesquisa código → Vê quantidade
Registar entrada de material Entradas → Nº PC ou entrada manual → Registar
Sacar material para obra Saídas → Código + quantidade + obra → Registar
Ver material de um poste Materiais por Poste → Nº poste → Ver lista
Fazer mapa de consumos Consumos → Datas → Exportar CSV → Excel
Mover material entre armazéns Transferências → Material + "De/Para" → Registar
Fazer backup de segurança Backup (JSON) → Guardar ficheiro

💡 DICAS DE OURO

  • ✅ Sempre preencher dados completos: Código, quantidade, data, origem/destino. Ajuda na auditoria.
  • ✅ Usar os filtros: Pesquisa, período, armazém. Economiza tempo a encontrar dados.
  • ✅ Verificar stock antes de sair: A app avisa se há falta. Nunca permite negativo.
  • ✅ Fazer backup regular: Mínimo 1x por semana ou antes de mudanças grandes.
  • ✅ Rastrear com documento/guia: Preenche nº de PC, guia AT ou documento SAP quando possível.
  • ✅ Exportar para Excel: Muitos relatórios permitem exportar CSV para análises adicionais.

❓ PERGUNTAS FREQUENTES

P: Posso fazer uma saída sem ter stock?
R: Não. A app avisa e não permite saída negativa. Primeiro ajusta o stock ou faz entrada.

P: Onde estão os dados realmente guardados?
R: Navegador (localStorage) + ficheiro HTML (SEED_DATA). Sempre faz backup para JSON.

P: Como restauro um backup antigo?
R: Clica "Restaurar", seleciona o ficheiro JSON. Atenção: substitui dados actuais.

P: Posso usar isto em móvel/tablet?
R: Sim! Layout adapta-se automaticamente. Dados sincronizam no navegador do dispositivo.

P: Como faço para conciliar com SAP?
R: Vai a "Relatórios", compara consumos/stock com dados SAP. Usa filtros de período.
