🎯 COMANDOS ESSENCIAIS
════════════════════════════════════════════════════════════════════════════════

OPERAÇÕES NORMAIS:

  .\orquestrador_seguranca.ps1 abrir MANUAL "Descrição"
    → Abre sessão segura (lock + backup)

  .\orquestrador_seguranca.ps1 fechar MANUAL -versioning
    → Fecha sessão (versioning + release lock)

  .\orquestrador_seguranca.ps1 status
    → Ver status geral do sistema

RECUPERAÇÃO:

  .\orquestrador_seguranca.ps1 recuperar MANUAL [backup_name]
    → Modo emergência (liberta lock + restaura backup)

VERIFICAÇÃO:

  .\sistema_versioning.ps1 get
    → Ver versões atuais

  .\sistema_backup.ps1 list MANUAL
    → Listar backups disponíveis

  .\sistema_lock.ps1 status
    → Ver locks ativos

════════════════════════════════════════════════════════════════════════════════

🔒 LOCK SYSTEM (Mutex)
   ✓ Apenas 1 agente mexe no ficheiro por vez
   ✓ Timeout automático após 30 segundos
   ✓ Limpeza automática de locks antigos
   ✓ Log completo de acessos

💾 BACKUP SYSTEM
   ✓ Cópia automática ANTES de cada alteração
   ✓ Histórico completo com metadados
   ✓ Limite automático: 10 versões por ficheiro
   ✓ Restauração em um comando

📊 VERSIONING SYSTEM
   ✓ Incremento automático de versão (MAJOR.MINOR.PATCH)
   ✓ Changelog completo
   ✓ Actualiza meta tags no HTML
   ✓ Integração com Service Worker

🆘 PROBLEMAS COMUNS
════════════════════════════════════════════════════════════════════════════════

PROBLEMA: "Não consegui adquirir lock"
SOLUÇÃO:  .\sistema_lock.ps1 cleanup
          .\orquestrador_seguranca.ps1 recuperar MANUAL

PROBLEMA: "Erro ao criar backup"
SOLUÇÃO:  Verificar espaço em disco
          Verificar permissões: C:\...\backups\ deve ter escrita

PROBLEMA: "Comando não encontrado"
SOLUÇÃO:  Colocar-se na pasta correcta:
          PS> cd "C:\Users\dst7973\Desktop\gestao_de_stocks_dte"
          PS> .\orquestrador_seguranca.ps1 ...

PROBLEMA: "Notificação não aparece"
SOLUÇÃO:  Verificar se update-notification.js está em ./app/
          Verificar Console do navegador (F12)
