PERGUNTAS FREQUENTES
================================================================================

P: O programa precisa de internet?
R: Não. Funciona completamente offline. Os dados são guardados localmente
   no navegador (localStorage). Para sincronizar entre computadores, usar
   backup/restauro via JSON.

P: Posso usar em vários computadores?
R: Sim, mas cada computador tem dados independentes (localStorage local).
   Para partilhar, usar a versão SharePoint e fazer sincronização manual
   via backup JSON.

P: E se o programa travar?
R: Fazer download de backup (botão "Backup" no programa). Depois restaurar
   quando o programa voltar a funcionar.

P: Quando fica pronto o programa para multi-utilizador?
R: Está planeado para Q4 2026. Será migrado para SharePoint Lists ou
   plataforma similar com acesso simultaneo.

P: Posso modificar os dados?
R: Sim, dentro do programa. As mudanças são guardadas automaticamente.
   Depois fazer backup se quiser guardar permanentemente.

P: Qual a diferença entre as versões?
R: Esta versão (20261015) tem 36 postes documentados vs. a anterior que
   tinha estrutura de postes mas sem dados de montagem dos cadernos.
