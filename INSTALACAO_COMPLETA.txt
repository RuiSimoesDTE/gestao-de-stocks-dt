OPÇÃO 1: Script PowerShell (Recomendado)
────────────────────────────────────────

Abra PowerShell na pasta do projeto e execute:

  # Apenas extração de texto e imagens
  .\ler-pdf.ps1 -PdfPath "desenho_306.pdf"

  # Com OCR em português
  .\ler-pdf.ps1 -PdfPath "desenho_306.pdf" -OCR -Lang por

  # Processar múltiplos PDFs
  Get-ChildItem "*.pdf" | ForEach-Object {
      .\ler-pdf.ps1 -PdfPath $_.FullName -OCR -Lang por
  }


OPÇÃO 2: Linha de comando direto
──────────────────────────────────

Converter PDF para imagens:
  pdftoppm -png desenho.pdf imagens/saida

Extrair texto:
  pdftotext desenho.pdf texto.txt

OCR em imagem:
  tesseract imagem.png resultado -l por


================================================================================
O QUE O SCRIPT FAZ
================================================================================

1. Extrai texto do PDF (pdftotext)
   → Ficheiro: documento.txt

2. Converte cada página em imagem PNG (pdftoppm)
   → Ficheiros: documento-1.png, documento-2.png, ...

3. Executa OCR em cada imagem (tesseract)
   → Ficheiro: ocr_resultados.json

4. Cria relatório de processamento
   → Todos os ficheiros em pasta: documento_extracted/

Exemplo de saída:
  desenho_306_extracted/
  ├── desenho_306.txt              # Texto extraído
  ├── desenho_306-1.png            # Página 1
  ├── desenho_306-2.png            # Página 2
  ├── ocr_resultados.json          # Resultados OCR
  └── ...

================================================================================
TROUBLESHOOTING
================================================================================

Erro: "pdftoppm: command not found"
→ Solução: Feche e abra nova janela PowerShell (PATH foi atualizado)

Erro: Teste com PDF e vê caracteres estranhos
→ Solução: Se PDF é imagem, usar OCR em vez de pdftotext

Erro: OCR muito lento
→ Solução: Usar PSM (page segmentation mode):
   tesseract imagem.png result --psm 6 -l por
